# iCoder

An Agentic AI toolchain to help you analyze your codebase and generate documentation, unittests, and more.

> Author: Soumen Sardar |
> Email: soumensardarintmain@gmail.com

```bash
pip install icoder
icoder <project_path>
```

## Dev Setup

- It is recommended to use: `uv`, follow this link: https://docs.astral.sh/uv/getting-started/installation/
- Once `uv` is installed just run `uv sync`
